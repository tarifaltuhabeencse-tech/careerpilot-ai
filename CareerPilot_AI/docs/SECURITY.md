# Security notes
Passwords are hashed; API routes require signed expiring JWTs; analyses are filtered by authenticated user ID; uploaded files are not executed and have size/type checks. This MVP does not include malware scanning, email verification, password recovery, account deletion, retention automation, secure cloud file storage, production rate limiting, or tested backup/recovery. The browser stores bearer tokens in localStorage. No AI provider receives CV data. Do not expose this development server publicly without HTTPS, production secrets, PostgreSQL, migrations, monitoring, backups, retention controls, and a security review.
